This repository contains solutions for Lab 4a covering DOM event listeners, input validation with conditional branching, and dynamic DOM node generation using native JavaScript (ES6) without external libraries.

`q1/` — Interactive Text Changer:** Uses `document.getElementById` and `addEventListener("click", ...)` to replace initial message text with `"Hello there!"` using `textContent`.
`q2/` — Smart Number Validator:** Reads user input, strips whitespace via `.trim()`, validates non-empty and numeric status, and categorizes input against the threshold of 10 (`< 10`, `> 10`, `=== 10`).
`q3/` — Dynamic Number Generator:** Uses a `for` loop (1 to 5) and `document.createElement("li")` to generate an ordered list, clearing child elements on each click to prevent duplicate list items.
